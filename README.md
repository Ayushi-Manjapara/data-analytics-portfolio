My data analytics portfolio showcasing projects in SQL, Python, Excel and data visualization

## Projects

### HDB Resale Price Analysis

An analysis of Singapore HDB resale transactions from
January 2017 to November 2026, exploring market trends,
town-level price differences, property age, and storey ranges.

**Tools:** MySQL

**Techniques used**
- Data quality assessment and preparation
- SQL aggregation, CASE expressions, and CTEs
- Window functions
- Year-on-year price comparisons
